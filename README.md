# Trustworthy-On-Chain-Off-Chain-Coordinated-Optimization-for-Multi-Park-Integrated-Energy-Systems
This study proposes an on-chain/ off-chain trustworthy coordination 6 approach based on the alternating direction method of multipliers (ADMM) and Mask– 7 KKT verification. ADMM decomposes the centralized problem into local park subproblems 8 and an on-chain global coordination problem.
